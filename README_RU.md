# Лупи приятеля — онлайн + Android APK

В проекте сохранена исходная игра и подготовлен переход с `claude.use()` на Firebase:
- анонимный вход Firebase Authentication;
- облачное сохранение прогресса игрока;
- общий рейтинг по деньгам;
- общий босс и учёт урона игроков;
- онлайн-счётчик через Firestore sessions;
- Capacitor-конфигурация для Android APK.

## 1. Настрой Firebase (делается один раз)

1. Открой https://console.firebase.google.com/ и создай проект.
2. В проекте добавь приложение Web (значок `</>`).
3. Скопируй конфигурацию Firebase в `www/firebase-config.js`, заменив все значения `ВСТАВЬ...` и `ТВОЙ...`.
4. В Firebase → Authentication → Sign-in method включи **Anonymous**.
5. В Firebase → Firestore Database создай базу данных.
6. Открой Firestore → Rules, вставь содержимое файла `firestore.rules` и опубликуй.

## 2. Проверка онлайн-версии

Опубликуй содержимое папки `www` на HTTPS-хостинге (например, GitHub Pages). Открой сайт на двух устройствах/в двух браузерах. Создай разные ники, проверь рейтинг, общий урон босса и облачное сохранение.

## 3. Сборка APK

Требуется Android SDK/Android Studio на компьютере либо облачная сборка. На одном Android-телефоне можно подготовить файлы в GitHub, но локально собрать полноценный APK обычно нельзя без среды сборки.

На компьютере с Node.js:

```bash
npm install
npx cap add android
npx cap sync android
npx cap open android
```

В Android Studio выбери Build → Build Bundle(s) / APK(s) → Build APK(s). APK появится в `android/app/build/outputs/apk/debug/`.

## Важно про честность и безопасность

Это подготовленная стартовая онлайн-версия, не финальная защищённая соревновательная платформа. Сейчас клиент отправляет свой игровой прогресс и деньги из браузера, поэтому технически опытный игрок может подделать их. Для рейтинга с реальными призами/соревнованиями нужно вынести начисление денег, покупки, награды за босса и админ-команды в Cloud Functions с серверной проверкой. Не публикуй секретные ключи и не считай скрытый PIN в HTML защитой админки.

## Файлы

- `www/index.html` — игра.
- `www/firebase-config.js` — настройки Firebase, которые нужно заполнить.
- `firestore.rules` — базовые правила доступа.
- `package.json`, `capacitor.config.json` — подготовка Android-приложения.
